VECTOR LIVE — CHROME / EDGE EXTENSION

1. Extract this ZIP and keep the vector-live-extension folder.
2. Open chrome://extensions or edge://extensions.
3. Enable Developer mode, choose Load unpacked, select the folder containing manifest.json.
4. Pin Vector from the browser extension menu. Crypto uses public Binance market data (no key).
5. For forex, open Vector Settings and enter a Twelve Data market-data key privately. Coverage, latency and quotas depend on your plan. Never share API keys in chat.
6. Use the expand button for the native side panel; on unsupported browsers a full extension tab is the fallback.
7. Open Page -> BUY / SELL / WAIT. Analyze your chart tab after clicking the toolbar icon, confirm the pair/timeframe, and record a paper prediction. The model is technical, not an external AI API.
8. Check outcomes later or explicitly enable background prediction checks. The local ledger records reference entry, stop, target, expiry and both-side costs BEFORE future bars. Pending/WAIT/ambiguous calls do not become claimed wins. Export the entire ledger before clearing it.

This package is locally loaded, not published to the Chrome Web Store. The extension uses polled market snapshots, not tick-by-tick streaming. No balances, cookies, screenshots or orders. A user-triggered temporary chart read inspects only bounded title/symbol/timeframe metadata; only the hostname is retained with a recorded call. Technical strength is not accuracy or probability. Real-market performance has not been independently validated. No guaranteed returns or passive income. API failures never fall back to demo prices.

Permissions: storage, alarms, sidePanel, activeTab, scripting. Temporary activeTab access only after your toolbar click; no permanent all-sites access or persistent content scripts. Network access: data-api.binance.vision and api.twelvedata.com only. Both background refresh and prediction checks are off by default. Predictions persist locally through restarts; clearing price cache does not erase results. 1-minute bars with both levels, unknown entry timing or missing history are ambiguous, not invented wins. Paper P&L excludes slippage, funding, borrow, taxes and actual broker fills; USD and USDT are separate. Credentials stay in local extension storage and are not synced or exported.
